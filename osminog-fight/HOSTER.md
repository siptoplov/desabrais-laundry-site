# Выкладка на hoster (обычный хостинг с Apache и PHP)

Сайт статический. Собранная папка `out/` целиком загружается в корень сайта (`public_html` или `www`).

## Нужно от хостинга
- Apache с `mod_rewrite`, `mod_headers` (есть почти везде) и PHP 7.4+ с расширением curl.
- Бесплатный SSL-сертификат (Let's Encrypt) на домен — включить в панели.
- Исходящие запросы на `api.telegram.org` (обычно разрешены).

## Шаги
1. Собрать: `NEXT_PUBLIC_SITE_URL=https://ВАШ-ДОМЕН npm run build` → появится папка `out/`.
2. Загрузить всё содержимое `out/` в корень сайта по FTP / файловому менеджеру. Включая скрытый файл `.htaccess`.
3. На сервере в папке `api/` скопировать `config.example.php` в `config.php`, вписать `bot_token` и `chat_id` (токен — только на сервере).
4. При обновлении сайта `api/config.php` не стирать (при загрузке не перезаписывать эту папку или загружать только изменённое).
5. Проверка: открыть сайт, отправить тестовую заявку с каждой формы — сообщения должны прийти в группу.

## Что делает `.htaccess`
Перенаправление на HTTPS, защитные заголовки (CSP, HSTS и др.), страница 404, кэш и сжатие, закрывает `config.php` от скачивания.
Проверить после загрузки: `https://ВАШ-ДОМЕН/api/config.php` должен отдавать 403, а не текст.

## Если PHP на хостинге нет
Формы перейдут в запасной режим: человек копирует текст заявки и отправляет в Direct. Тогда приём заявок надо вынести на отдельный сервис (например, оставить функцию на Netlify).
