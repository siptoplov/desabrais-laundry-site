# Запуск сайта «Осьминог» — чек-лист

Сайт: https://osminog-fight.netlify.app (Netlify, статическая сборка Next.js).

## Сделано в коде

**Защита от ботов и спама**
- Все формы (заявки бойцов и спонсоров, подписка, лист ожидания билетов, контакты, мерч, «Рубаха-парень»)
  уходят в одну форму Netlify Forms `zayavka` (каркас — `public/__forms.html`, отправка — `src/lib/forms.ts`).
- Спам режут: фильтр Akismet (встроен в Netlify Forms), скрытое поле-ловушка `_hp`,
  проверка времени заполнения (быстрее 2,5 с — отказ).
- Если сервис форм недоступен — запасной режим: готовый текст заявки для Direct в Instagram.

**Безопасность (`public/_headers`)**
- Content-Security-Policy: свои скрипты и стили, картинки YouTube, встраивание только youtube-nocookie;
  запрет встраивания сайта в чужие фреймы, запрет плагинов, отправка форм только на свой домен.
- HSTS, X-Frame-Options DENY, nosniff, Referrer-Policy, COOP, Permissions-Policy (камера, микрофон, гео, оплата — выкл.).
- Проверено в браузере: нарушений политики нет, видео, 3D и формы работают.

**SEO**
- Адрес сайта для поисковиков — `NEXT_PUBLIC_SITE_URL` в `netlify.toml` (сейчас адрес Netlify).
- У всех 190 страниц: title, description, canonical, картинка для соцсетей; карта сайта `/sitemap.xml`.
- Разметка schema.org: лига (SportsOrganization), турниры (SportsEvent), бойцы (Person), новости, хлебные крошки.
- Места для кодов Google Search Console и Яндекс.Вебмастера — переменные `NEXT_PUBLIC_GOOGLE_VERIFICATION`,
  `NEXT_PUBLIC_YANDEX_VERIFICATION` в `netlify.toml`.

**GEO / ИИ-поиск**
- `/llms.txt` — справка для ИИ-поисковиков: лига, следующий турнир, чемпионы, все турниры с итогами боёв, разделы.
- `robots.txt` явно разрешает ИИ-поисковики (ChatGPT, Claude, Perplexity, Gemini, Apple, Яндекс), закрыты только
  личный кабинет и служебный каркас форм.

**Данные**
- «Осьминог-11» — 11 февраля 2027, отсчёт до 18:00 по Минску (время и площадку — уточнить).
- Итоги боёв сверены с объявлениями ведущих на записях Rutube (распознавание речи) и кадрами награждения.

## Сделать вручную (в панели Netlify / у владельца)

1. **Выложить сайт** (деплой) — после согласия владельца.
2. **Открыть сайт для всех**: Netlify → Site configuration → Access & security → Visitor access → снять пароль.
   Пока сайт закрыт паролем, поисковики и ИИ его не видят.
3. **Включить приём форм**: Netlify → Forms → Enable form detection, затем передеплой.
   Там же — Form notifications → e-mail, куда присылать заявки.
4. **Свой домен** (например, osminog.by): купить, подключить в Netlify → Domain management,
   поменять `NEXT_PUBLIC_SITE_URL` в `netlify.toml`.
5. **Поисковики**: добавить сайт в Google Search Console и Яндекс.Вебмастер, вписать коды подтверждения
   в `netlify.toml`, отправить `/sitemap.xml`.
6. **«Осьминог-11»**: время начала, площадка, кард, ссылка на продажу — `src/content/events.ts`.
7. Фото бойцов без портрета (44, в основном 2016 год, «Проект Осьминог», «Осьминог-2/3») — прислать фото,
   портреты вырезаются под формат сайта.
