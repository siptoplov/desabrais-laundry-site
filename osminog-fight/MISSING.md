## 5. Telegram-бот (делаем следующим)
1. В Telegram откройте @BotFather → `/newbot` → имя и ник бота → скопируйте токен.
2. Создайте группу для заявок, добавьте туда бота и сделайте его админом.
3. Если нужны темы (боец / партнёр / рубаха), включите в группе «Темы» (форум). Id тем — необязательно.
4. Узнать id группы: напишите что-нибудь в группе, откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":-100…}`.
5. Netlify → Project configuration → Environment variables: `TG_BOT_TOKEN`, `TG_CHAT_ID` (по желанию `TG_THREAD_FIGHTER`, `TG_THREAD_PARTNER`, `TG_THREAD_RUBAHA`, `TG_THREAD_OTHER`).
6. Одна выкладка (15 кредитов), затем тестовая заявка с каждой формы.
