# Мерч ОСЬМИНОГ · коллекция 01 «Глубина»

Четыре модели, каждая в чёрном и белом. Красный только в деталях: глаза осьминога, кант, полосы на воротнике поло. Все принты в две краски.

| Модель | Спереди | Сзади | Детали |
|---|---|---|---|
| Футболка «Знак» | 01 на груди слева, 9 см | 02 на спине, 28 см | горловина из рибаны в цвет ткани |
| Поло «Секундант» | 01 вышивкой, 7 см; 05 на правом рукаве | 04 под воротником | красная полоса на воротнике и манжетах |
| Майка «Восемь ударов» | 03 на груди, 23 см | 04 под горловиной | окантовка бейкой |
| Шорты «Октагон» | 06 на поясе; 01 на левой штанине, 15 см; 07 вдоль шва правой | 01 на поясе, 7 см | красный кант по поясу и разрезам |

Размеры принтов даны для размера M. «Левая» и «правая» здесь со стороны того, кто носит вещь.

## Файлы

- `print/` — принты в SVG, размер в миллиметрах, текст переведён в кривые. Для шелкографии и вышивки.
- `png/` — те же принты в PNG 300 dpi с прозрачным фоном. Для DTF. Знак 01 выгружен в 15 см (самый крупный размер), его можно уменьшать.
- `mock/` — макеты изделий спереди и сзади.

У каждого принта два варианта: `_on-black` — для чёрной ткани (белая и красная краска), `_on-white` — для белой (чёрная и красная).

Красная краска #FF2B3A. Ближе всего к ней PANTONE 1788 C или Red 032 C, точный цвет подобрать по выкрасу. Белую на чёрной ткани печатать с подложкой.

## Как пересобрать

Принты и макеты рисует `build.py`: логотип он берёт из `src/components/brand/logoPaths.ts`, шрифт Sofia Sans Extra Condensed (лицензия OFL) из `src/fonts`. Запуск из папки `osminog-fight`:

```bash
pip install fonttools brotli uharfbuzz
python merch/build.py        # merch/print и merch/mock
node merch/png.mjs merch     # merch/png, нужен playwright
```
